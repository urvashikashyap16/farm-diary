SEVA First Innovation Challenge 2026. Participant: Urvashi Kashyap (solo).

## Notes

- Open-source tools carry no licence fee: Vosk (offline speech), AI4Bharat IndicConformer (optional server model), React Native, SQLite.
- Own laptop is used for development (not costed).
- Cloud starts on a free tier (Firebase or Supabase); the ₹3,000 is a reserve.
- **Unit cost:** copying the app to another farmer costs nothing. Running cost per farmer is near zero: text-only sync, well under 100 KB a year.
